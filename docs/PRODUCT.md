## 3. 全局筛选器（吸顶 FilterBar）

| 筛选项 | 说明 |
|---|---|
| 日期区间 | 日历选择；**默认 = 上一个自然周**（周一~周日，保证 T+1 数据完整）；重置按钮恢复默认 |
| 销售站点 | Shopify / Shoplazza 多选，支持「排除」模式（选中的为排除项） |
| Meta 账号 | 多选 + 搜索 + 全选/反选 + 排除模式 + 批量粘贴 |
| Google 账号 | 同上 |
| 环比配置 | 开关 + 周期类型（周/月/年/自定义）+ 对比期数 N + 每期区间可手动覆盖 |

交互约定（观远式）：筛选修改先入**草稿态**，点【应用】才生效（按钮高亮提示未应用变更）；生效筛选在 sessionStorage 持久化，跨刷新/跨 tab 保留。大盘页仅联动日期与站点，账号筛选不影响大盘卡片。

## 4. 环比与归因分析

- **环比呈现**：开启环比后，全部 KPI 卡与表格数值旁显示对比期小字与涨跌色；对比期 = 周期类型 × N 期自动推算（如周环比=上一自然周），可逐期自定义覆盖。
- **涨跌色**：涨绿跌红；高亮阈值——钱效率组（CVR/ROAS/AOV）>5%，流量效率组（CPM/CPC/CTR）>10%。
- **环比归因浮层**（大盘三表专属）：表格 Δ 格 hover 时，自动给出**五维度（账号/商品/素材类型/国家/年龄段）环比 Top3** 变化对象（增长/下降各取 3，上期基数为 0 与 unknown 不参与）；点击对象直接跳转对应明细页（如 Meta·商品 → `/meta/m3`）。

## 5. 指标体系

所有派生指标由 `shared/metrics.ts` 唯一实现（前后端/管道共用），总计行 = Σ分子/Σ分母 重算，禁止对比率求平均。

**Meta 标准四组（16 列）**：

| 分组 | 指标 |
|---|---|
| 投放规模 | 花费、展示、点击、订单、转化价值 |
| 流量效率 | CPM、CPC、CTR |
| 转化效果 | CVR、单次加购、单次结帐、单次购买 |
| 投产回报 | ROAS、客单价 |

**Google 双口径**：vs＝Shopify 归因转化价值（**考核口径**，ROAS(Shopify)）、va＝Ads 后台平台回传（**投放参考**，ROAS(Google)）；大盘/账号/国家/年龄表双口径并列，明细表按 tab 选单口径。

表头悬浮显示口径提示（TH_TIP），如「CVR＝订单÷全部点击（Meta 口径）」「vs：attribution 归因，考核口径」。

## 6. 数据口径（业务层）

- **Meta 点击**：链接点击口径（CVR 分子）；CVR 分母用「全部点击」桶位（inter）。
- **Google 点击**：Google Ads 后台点击口径（platform clicks，与 Ads 后台一致）。
- **EDM**：Shopify 订单的 Klaviyo 邮件归因销售额（退货后口径），无广告花费，计入大盘转化价值；2026-09 起有数。
- **整站 GMV**：易仓已付款订单（status=4）按下单日期，按选中站点求和。
- **已知边界**：Meta 对分维度数据有平台内部取整，国家/年龄模块与 Meta 前端可能有个位数出入；整站 GMV 为 T+1 快照，历史订单状态次月回填期间数值逐日收敛（口径说明弹窗有完整文案）。
