# 广告流量分析看板 · 使用指引

> 面向投放业务同事 ｜ 简明版

**看板地址**：https://whatsblue.github.io/ads_analysis_dashboard_normal/

---

## 一句话介绍

一个看 Meta、Google 广告投放效果的网页看板：不用登多个后台，打开就能看花费、订单、转化价值、ROAS 等核心指标，并能按账户、商品、素材、国家、年龄等维度层层拆解定位问题。

## 数据更新节奏

- 每天**凌晨 05:00** 自动同步截至昨日的数据（T+1）。
- 平台白天迟到的数据回传，会在**晚间批次**自动补齐。
- 页面右上角徽章显示**最近一次数据更新时间**，看到徽章即可确认数据新鲜度。

## 三步上手

1. **选日期范围**：默认上一个自然周（周一至周日），可改任意区间。
2. **选销售站点 / 广告账号**：不选 = 全部。
3. **点「应用」**：下方所有图表和表格随筛选生效。

## 页面导览

| 页面 | 看什么 | 典型问题 |
|---|---|---|
| **大盘** | Meta + Google 合并的整体健康度（花费 / 订单 / 转化价值 / ROAS / GMV 等） | 大盘今天花多少、效果怎么样 |
| **Meta > 大盘健康度** | Meta 渠道整体趋势与核心指标 | Meta 大盘趋势如何 |
| **Meta > 账号定位** | 各广告账号的量级与效率 | 哪个账户花得多、哪个账户效率高 |
| **Meta > 商品投产** | 各商品（SPU）的投放产出 | 哪个商品值得加投、哪个该降预算 |
| **Meta > 素材效率** | 各素材 / 素材类型的跑量与转化 | 哪条素材在跑量、哪类素材值得复制 |
| **Meta > 国家维度** | 各国市场表现，含 US / Non-US 对比 | 哪些国家在出单、该拓哪个市场 |
| **Meta > 年龄维度** | 各年龄段受众表现 | 投给谁、预算往哪个年龄段倾斜 |
| **Google > 大盘健康度** | Google 渠道整体趋势 | Google 大盘趋势如何 |
| **Google > 账号定位 / 商品投产 / 国家维度 / 年龄维度** | 与 Meta 同名页签逻辑一致 | 同上 |
| **Google > 广告类型分析** | 各广告类型与品牌 / 非品牌词的表现 | 搜索 / 购物等类型谁更有效率 |

## 筛选条件说明

| 筛选项 | 说明 |
|---|---|
| 日期范围 | 默认**上一个自然周**（周一至周日），可改任意区间 |
| 销售站点 | Meta 数据可选 Shopify / Shoplazza；Google 数据目前仅覆盖 Shopify |
| 广告账号 | 可多选，支持搜索与批量粘贴；不选 = 全部账号 |

注意：

- 修改筛选后需点**「应用」**才生效，**「重置」**恢复默认。
- 「大盘」页总览卡只受日期和站点影响，**广告账号筛选不影响它**。

## 环比对比

- 勾选**「开启环比」**：明细表每行下方会多出对比期数据与涨跌百分比，图表同步叠加对比曲线。
- **「环比设置」**可选对比基准（上一周期 / 上月 / 去年同期 / 自定义）与对比周期数（1-4 个）。
- 按钮颜色含义：**蓝色** = 有修改未应用；**灰色** = 环比开启中；**白色** = 未开启。

## 表格小技巧

- **排序**：点击任意指标表头，按该列降序 / 升序切换（包括「花费占比」等占比列）。
- **显示占比**：勾选后出现各指标占当前筛选范围总量的百分比列。
- **加载更多**：明细默认显示前 10 行，点底部按钮查看全部。
- **展开细分**：部分明细表首列可点击展开，查看编号下的广告级细分。
- **悬浮提示**：鼠标停在指标表头可看口径说明；停在环比涨跌格可看涨跌归因拆解。
- **导出**：点「⇩ 导出」后可勾选所需列、拖动调整列顺序、选择区间汇总或按日粒度、xls / csv 格式；页面若开启了环比，导出文件同样包含环比行。

## 颜色与高亮标准

看板用颜色帮你快速定位波动，规则统一如下：

| 颜色 / 样式 | 含义 |
|---|---|
| 绿色 ↑（如 ↑ 10.67%） | 该指标环比**上涨**（涨=绿） |
| 红色 ↓（如 ↓ 2.83%） | 该指标环比**下跌**（跌=红） |
| 环比行浅色底纹 | 环比数据的衬底，数字为涨跌百分比，无涨跌时显示 — |
| **黄色高亮底** | 环比波动幅度**过大**的提醒（见下方阈值），涨跌都会触发 |
| 表头 ▼ / ▲ 蓝色箭头 | 当前排序：▼ 降序、▲ 升序 |

**黄色高亮的触发标准**（环比变化幅度取绝对值，上涨或下跌超过阈值即高亮）：

| 指标 | 高亮阈值 |
|---|---|
| CVR、ROAS、客单价 | 波动 **> 5%** |
| CTR、CPM、CPC | 波动 **> 10%** |
| 其他指标（花费、订单、转化价值等） | 不高亮 |

注意：

- 黄色高亮仅作用于 **Meta 系列表**；Google 系列表不启用该提醒。
- 对比期缺失数据（如新开账户无上月数据）时环比显示 —，不参与高亮。

## 常见问题（FAQ）

**Q1：数据什么时候更新？**
每天凌晨自动同步截至昨日的数据；白天迟到的平台回传会在晚间批次补齐。以页面右上角徽章时间为准。

**Q2：看板数字和 Meta / Google 后台对不上？**
看板取自平台官方导出报告口径，Meta 后台修改归因设置不会联动看板数据；核对请以后台导出报告为准（详见看板右上角「口径说明」）。

**Q3：国家 / 年龄细分的汇总数和总览有个位数差异？**
平台对分维度数据有内部取整，属正常现象，不影响汇总准确性。

**Q4：筛选了账号，为什么大盘总览数字没变？**
大盘页总览卡设计上只跟随日期范围与销售站点，用于固定基准观察；拆解请看 Meta / Google 各明细页。
