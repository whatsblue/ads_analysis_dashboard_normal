# 广告流量分析看板 · 功能说明

> 访问地址：https://whatsblue.github.io/ads_analysis_dashboard_normal/
> 数据更新：T+1 每日自动同步（页面右上角展示最近一次更新时间，如「2026-11-17 11:53（T+1 05:00 自动同步）」）
> 数据口径：大盘花费/GMV 与观远 BI 对齐；GMV 链路含 EDM 归因销售额口径（详见「口径说明」页内入口）

## 一、页面导航

看板为两级导航结构：

| 一级 | 二级页面 | 说明 |
|---|---|---|
| 大盘 | 大盘 | 全渠道总览（首页） |
| Meta | 大盘健康度 / 账号定位 / 商品投产 / 素材效率 / 国家维度 / 年龄维度 | Meta 广告 6 个分析视角 |
| Google | 大盘健康度 / 账号定位 / 商品投产 / 广告类型分析 / 国家维度 / 年龄维度 | Google 广告 6 个分析视角 |

## 二、顶部筛选栏（全局生效）

- **日期范围**：默认为上一个自然周（周一 ~ 周日）；可自定义起止日期（双月日历，选择起止后自动收起）。
- **销售站点**：按站点切换数据视角；站点可用集合随数据动态变化。Shoplazza 站点满足条件时显示对应入口，AE/SA 站点默认开启对比。
- **广告账号**：Meta 账号下拉仅展示当前所选站点下有投放的账号（账号宇宙按站点映射过滤，且限定所选区间）。
- **开启环比**：勾选后明细表追加对比行；配合「环比设置」定义对比方式。
- **环比设置 / 应用 / 重置**：见下节；「口径说明」弹窗提供各指标口径定义。
- 未选态筛选器显示引导文案（如广告账号「请选择」）；筛选变更后需点「应用」生效，「重置」恢复默认。

## 三、环比功能

点击「环比设置」打开设置弹窗（左右两栏布局）：

- **左栏配置**：
  - 环比类型：上周同期 / 上月同期 / 去年同期 / 自定义周期；
  - 环比周期数：1 ~ 4（各对比期按所选类型依次前推）；
  - 各周期时间范围：按类型自动预填，点击任一周期行，右侧日历即时展开该周期供修改。
- **右栏日历**：常驻展示当前选中周期的双月日历；点选起止日期后区间即时回显，全程弹窗无滚动条。
- **保存**：仅「自定义周期」保留手动修改的时间范围；保存后生效并开启环比，明细表中间插入对应组数的对比行。
- **关闭弹窗不保存**：未应用的编辑自动回滚（从生效值重置）。
- 导出时环比对比行同步导出；比率类指标在导出中显示为百分比。

## 四、通用明细表交互

- **显示占比**：明细表可勾选「显示占比」追加占比列（默认不勾选）；占比列表头可点击升/降序排序。
- **表头吸顶**：宽表滚动时表头页面级吸顶；Campaign 明细表「Campaign ID」「Campaign 名称」双列冻结（横向滚动时始终可见）。
- **Campaign ID / 名称**：明细按系列 ID 分桶统计（同名不同 ID 的系列不会合并）；下拉筛选展示系列名称。
- **无效数据过滤**：无投放/空值行按规则过滤，不进入明细与占比分母。
- **图表悬浮提示**：悬浮查看数值，提示框自动防遮挡。
- **导出**：各表格支持导出 .xls；数值保持千分位格式，比率指标导出为百分比，环比行随表导出。

## 五、页面功能明细

### 大盘（首页）
- **大盘总览**：渠道 × 花费 / GMV / GMV 占比 / ROAS 汇总表（整站合计 + Meta / Google / EDM 分行），支持导出。
- **花费 & ROAS 趋势**：双轴趋势图，按日 / 按月 / 按年切换。
- **渠道花费占比 / 渠道 ROAS 对比**：渠道结构对比图。

### Meta
- **大盘健康度**：花费 & ROAS 趋势，及花费 / 订单 / 转化价值 / 客单价核心指标。
- **账号定位**：账号与 Campaign 明细表（Campaign ID + 名称双列冻结；支持显示占比与排序；名称下拉筛选）。
- **商品投产**：商品（SPU）维度花费 / 销售投产对比明细。
- **素材效率**：素材类型 ROAS 对比、素材类型占比、素材子分类明细；视频素材按新旧分类并补充「其他」行；支持从子分类返回类型明细；单周期压缩列距、多周期提供滑块。
- **国家维度**：国家对比明细（国家下拉动态过滤有效数据，至多选 2 项对比，未选态显示引导文案）；支持 Non-US 合计与国家维度拆分表（标题按规范命名）；Meta 国家筛选器有提示文案规范。
- **年龄维度**：年龄段 ROAS 对比、年龄段占比。

### Google
- **大盘健康度**：Google 双口径对照——（考核）ts 口径与（投放优化）Ads 后台口径；含花费 / ROAS(Ads 后台) / 客单价 / 品牌词花费占比。
- **账号定位**：Google Campaign 明细表（同 Meta：ID + 名称双冻结、占比、排序）。
- **商品投产**：Google 商品维度投产明细。
- **广告类型分析**：说明 Ads 后台（平台回传，用于投放优化）与口径差异；Google 广告类型花费分布、广告类型 ROAS 对比。
- **国家维度 / 年龄维度**：同 Meta 对应维度的对比结构。

## 六、数据与技术说明

- **数据链路**：ReOrc 管道每日 T+1 拉取 Meta / Google 广告后台与订单数据，按月度分片存储全历史（自 2025-01 起），契约版本 v5（Campaign 按系列 ID 分桶）。
- **口径对齐**：大盘花费 / GMV 逐日与观远 BI 对齐校验；Google 双口径（考核 / 投放优化）分开展示；EDM 归因销售额计入 GMV 链路。
- **前端**：Vue 3 + Vite + Pinia；静态托管于 GitHub Pages，发布后自动更新。
